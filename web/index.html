    About The Librarian

    A question-answering assistant for the Web Content Accessibility Guidelines (WCAG) 2.2, built for the CS496 AI Engineering course. It uses retrieval-augmented generation (RAG):

    1. 1Searches 557 W3C pages by keywords and by meaning.
    2. 2A reranker keeps the 5 most relevant passages.
    3. 3An LLM answers using only those passages and cites them.
    4. 4If nothing relevant is found, it says it doesn't know.

    It can still make mistakes. Always check the cited W3C source before relying on an answer.
